About This Analysis

📊 What Was Simulated?

10,000 Monte Carlo simulations explored uncertainty in:

  • Capital costs (sensor nodes, interceptors, AI development)
  • Operating costs (personnel, maintenance, fuel, interceptors)
  • Deployment timelines (prototype, partial, full)
  • Technical performance (AI accuracy, network availability)
  • Threat environment (Kinzhal attack rates, EW effectiveness, SEAD attrition)

🔄 How to Reproduce

The entire analysis is open source and reproducible:

  1. Clone the repository: git clone https://github.com/tobias-weiss-ai-xr/open-rocket-defense-system-research
  2. Install dependencies: pip install numpy pandas
  3. Run simulation: python3 scripts/monte_carlo_defense_analysis.py
  4. View results: Check research/ directory
  5. Deploy site: Enable GitHub Pages on site/ folder

Note: Simulations take 2-5 minutes to run with 10,000 iterations

⚠️ Limitations

This analysis has several limitations:

  • Does not model Russian counter-adaptations over time
  • Assumes static threat environment
  • Does not include political/supply chain constraints
  • Cost estimates are pre-war (2024) dollars
  • Timeline assumes no material shortages
  • Does not account for training/learning curve effects

For more details, see: research/open-rocket-defense-systems.md
