# Cost Framework for Missile Defense Analysis

## Cost Categories

### 1. Capital Costs
- System acquisition
- Infrastructure
- Training facilities

### 2. Operational Costs
- Personnel
- Maintenance
- Deployment
- Training

### 3. Engagement Costs
- Interceptor/ammunition cost
- Power/fuel
- Wear and tear

### 4. Opportunity Costs
- System availability
- Coverage gaps
- Strategic trade-offs

## Metrics

### Cost Per Engagement
```
CPE = (Interceptor Cost + Support Cost) / Successful Intercepts
```

### Cost Exchange Ratio
```
CER = Interceptor Cost / Threat Cost
```

### Cost Effectiveness
```
CE = (Threats Neutralized × Threat Value) / Total System Cost
```

## Data Sources
- Manufacturer specifications
- Government procurement records
- Think tank analyses
- Open source intelligence
