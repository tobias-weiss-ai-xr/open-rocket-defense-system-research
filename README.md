# Ukrainian Missile Defense: Cost-Effective Alternatives

## Research Goal
Identify cost-effective alternatives to the Patriot system for protecting Ukrainian civilians from Russian rocket/missile attacks.

## Project Structure
```
├── README.md              # Project overview
├── research/              # Main research documents
│   └── ukraine-missile-defense-analysis.md
├── docs/                  # Technical documentation
├── data/                  # Data files and datasets
├── sources/               # Source materials and citations
└── analysis/              # Analysis outputs and visualizations
```

## Research Areas
1. Russian offensive systems (Kinzhals, Iskanders, Kalibrs, drones)
2. Patriot system analysis (cost, effectiveness, limitations)
3. Alternative defense systems (Iron Dome, IRIS-T, NASAMS, etc.)
4. Cost-effectiveness analysis
5. Civilian protection strategies
